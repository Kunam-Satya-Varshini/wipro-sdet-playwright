//1 app.html

This program is a basic HTML webpage representing a home page of a website.
It contains a heading and a paragraph describing the page content. 
The page also includes navigation links using an unordered list.
These links allow the user to move to other pages like the login page and about page. 
This is useful for creating simple website navigation between multiple pages.

//2 app.js

This program defines a JavaScript login function that validates user credentials.
It retrieves the username and password entered in input fields using DOM methods.
The function checks whether the entered values match predefined credentials. 
If the login is successful, it shows a success message and redirects the user to another page.

//5 login.html
This program is a basic HTML login page that allows users to enter their username and password
It includes input fields for user credentials and a button to trigger the login process. 
The page is connected to an external JavaScript file for handling login functionality. 
It also links a CSS file to style the page.
When the user clicks the login button, a function is called to validate the entered details. 
This demonstrates basic form handling, file linking, and user interaction in a web application.
